特性

小而锋利的工具,只做一件事

没有账号、没有数据库、没有历史包袱 —— 用完即走的临时信道。

三页结构,零学习成本

首页选择、扫码上传、观看端各自独立。打开就知道怎么用,不用读文档。

服务端渲染二维码

前端只放一个 <img>,零依赖。中文、特殊字符编码不用操心。

取景框优先扫码

先只解取景框内的画面,框里没有再回退全画面,又快又准。

上传鉴权,观看开放

知道分享码能看,但往频道里塞内容需要 uploadToken。看与写的权限分离。

历史可回看

最近 200 条记录,点任意一条回看当时那张码。只在内存,刷新即失。

全内存,即用即走

没有数据库,容器重启即清空。天然的"临时信道",什么都不留。

开箱的限流防护

上传频率、频道查询、频道总数全部可配,穷举分享码也撞不开门。

轻得不像话

镜像压缩后 60 MB,运行内存约 27 MB。一台最小的 VPS 就能跑。

部署

三条命令,跑起来

Docker 一键脚本,回车即默认值。IP 自签证书或域名 Let's Encrypt 都已备好。

terminal 
# 克隆并启动,一路回车用默认值
$ git clone https://github.com/Xiaodu2638/Live-QRCode.git
$ cd Live-QRCode
$ ./setup.sh

# 部署完成
✓ 首页     https://你的IP:8443/
✓ 上传端   https://你的IP:8443/upload
✓ 观看端   https://你的IP:8443/view

域名模式

setup.sh 里选 2,自动申请 Let's Encrypt 证书,客户端零配置。

IP 模式

内置 CA 自签证书,10 年有效期;装一次根证书,扫码摄像头立即可用。

不想 Clone?

直接用公开镜像拉起,docker-compose.image.yml 一行不差。
